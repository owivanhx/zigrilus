# Zigrilus ✿

Pagininha pessoal em HTML, CSS e JS puros (sem dependências).

## Estrutura
```
index.html
css/style.css
js/script.js
images/ (avatar, xadrez, lirios, gato, tenis)
```

## Como publicar no GitHub Pages
1. Crie um repositório (ex.: `zigrilus`) e envie todos os arquivos mantendo as pastas.
2. Vá em **Settings → Pages**.
3. Em *Source*, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. Aguarde um minuto: o site fica em `https://SEU-USUARIO.github.io/zigrilus/`.
